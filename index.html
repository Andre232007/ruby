O que é Ruby?

Ruby é uma linguagem de programação dinâmica, orientada a objetos, criada por Yukihiro "Matz" Matsumoto em 1995 no Japão. Sua filosofia é simples: tornar a programação mais produtiva e divertida.

Tipagem Dinâmica

Ruby possui tipagem dinâmica, o que significa que você não precisa declarar o tipo das variáveis. O tipo é determinado automaticamente em tempo de execução.

# Ruby determina o tipo automaticamente
nome = "João"        # String
idade = 25           # Integer
altura = 1.75        # Float
ativo = true         # Boolean
lista = [1, 2, 3]    # Array

# O comando 'puts' exibe valores na tela
puts nome            # Saída: João
puts idade.class     # Saída: Integer
puts altura.class    # Saída: Float

O que é 'puts'?

puts é um método que exibe valores na tela, similar ao console.log do JavaScript ouprint do Python.

Super Bombinhas

Um jogo de plataforma 2D completo desenvolvido inteiramente em Ruby!

Sobre o Jogo

Super Bombinhas é um jogo de plataforma retrô inspirado em clássicos como Super Mario World, mas com uma mecânica única de troca de personagens. Foi construído usando Ruby com as bibliotecas Gosu e MiniGL.

Características:

  • •Jogo de plataforma 2D completo
  • •Mecânica única de troca de personagens
  • •Editor de níveis incluído
  • •Múltiplos modos de jogo
  • •Código fonte aberto (GPL-3.0)
